# Sri Shankar N — Portfolio Website

A lightweight, responsive personal portfolio site built with plain HTML, CSS, and JavaScript to showcase projects, skills, and contact information.

**Live preview:** This site is published at https://srishankar2006.github.io/Portfolio/

---

**Summary:**
- Single-page portfolio with sections for Home, About, Skills, Projects, GitHub snapshot, and Contact.
- Interactive UI elements: particle background, theme toggle, scroll reveal, project modals, and tilt effects.

**Key files:**
- [index.html](index.html) — Main site markup and structured data.
- [style.css](style.css) — Theme-aware styling, layout, and responsive rules.
- [script.js](script.js) — Theme handling, navigation, modals, contact form behavior, and GitHub API fetch.
- [robots.txt](robots.txt) — Sitemap reference for crawlers.
- [sitemap.xml](sitemap.xml) — Sitemap entries for the site.

**Technologies & libraries used**
- HTML5, CSS3, JavaScript (Vanilla)
- Particles.js for background effects
- ScrollReveal.js for scroll animations
- VanillaTilt.js for 3D card tilt
- Google Fonts (Poppins) and Font Awesome icons

**How to run locally**
1. Open `index.html` in your browser (no build step required).

```bash
# from the project folder (optional) you can serve locally, for example with Python 3:
# (this is only a convenience HTTP server; it does not mean Python code is used by the site)
python -m http.server 8000
# then open http://localhost:8000/
```
